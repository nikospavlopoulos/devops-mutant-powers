# Security policy

## Reporting a vulnerability

Report vulnerabilities privately. Open this repository's **Security** tab, choose **Report a vulnerability**, and fill in the form. This uses GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

Never open a public issue for a vulnerability.

## Scope

In scope: the plugin's scripts, hooks and tooling templates.

Out of scope: vulnerabilities in third-party tools the skills mention, and in the agent harnesses themselves. Report those to their own projects.

## What to include

- What is affected (file or template) and the plugin version.
- Steps to reproduce, using generic examples.
- The impact you expect.

Do not include real secrets, hostnames or private data in a report.
