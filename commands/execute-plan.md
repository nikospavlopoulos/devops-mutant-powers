# /execute-plan

Invoke the executing-plans skill to execute an existing implementation plan inline in this session: you implement each task yourself, and one fresh reviewer checks the whole branch at the end. For a fresh implementer subagent per task, use `devops-mutant-powers:subagent-driven-development` instead.

Use the Skill tool to load `devops-mutant-powers:executing-plans` and follow its process.
