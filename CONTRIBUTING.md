# Contributing

Contributions are made through issues. Pull requests are not accepted, because the project is maintained in a private repository and published by export.

## Open an issue for

- **Bug:** something in the plugin's files or scripts is broken. Use the [bug form](https://github.com/nikospavlopoulos/devops-mutant-powers/issues/new?template=bug.yml).
- **Misbehaviour:** a skill did not make the agent behave in a disciplined way. Use the [misbehaviour form](https://github.com/nikospavlopoulos/devops-mutant-powers/issues/new?template=misbehaviour.yml).
- **Idea:** a new skill, or an improvement to one. Use the [idea form](https://github.com/nikospavlopoulos/devops-mutant-powers/issues/new?template=idea.yml).

## Before you post

Never paste secrets, hostnames or private data into an issue. Replace them with generic placeholders.

For security vulnerabilities, do not open an issue. Follow [SECURITY.md](SECURITY.md).
